# دليل البدء السريع - نظام الصلاحيات

## 🚀 الوصول السريع

### لوحة التحكم الرئيسية
```
http://jabalia.test/permissions/dashboard
```

### الصفحات الرئيسية
- **المستخدمين:** `/permissions/users`
- **الأدوار:** `/permissions/roles`
- **الصلاحيات:** `/permissions/permissions`

## 👤 إدارة المستخدمين

### 1. عرض المستخدمين
- افتح صفحة `/permissions/users`
- استخدم الفلاتر للبحث بالاسم، الدور، أو الحالة
- عرض إحصائيات فورية في أعلى الصفحة

### 2. تعديل أدوار المستخدم
- اضغط على زر "تعديل الأدوار" بجانب المستخدم
- حدد/ألغِ الأدوار المناسبة
- احفظ التغييرات

### 3. إعادة تعيين كلمة المرور
- اضغط على زر "تعيين كلمة مرور"
- أدخل كلمة المرور الجديدة
- تأكيد كلمة المرور
- احفظ

### 4. حذف مستخدم
- اضغط على زر الحذف (أيقونة القمامة)
- تأكيد الحذف

## 🏷️ إدارة الأدوار

### 1. عرض الأدوار
- افتح صفحة `/permissions/roles`
- استخدم الفلاتر للبحث بالاسم أو التصنيف
- عرض إحصائيات عن الأدوار والصلاحيات

### 2. إضافة دور جديد
- اضغط "إضافة دور"
- أدخل اسم الدور
- حدد الصلاحيات المناسبة
- احفظ

### 3. تعديل دور
- اضغط "تعديل" بجانب الدور
- عدل الاسم والصلاحيات
- احفظ التغييرات

### 4. حذف دور
- اضغط على زر الحذف
- تأكيد الحذف

## 🔑 إدارة الصلاحيات

### 1. عرض الصلاحيات
- افتح صفحة `/permissions/permissions`
- استخدم الفلاتر للبحث بالاسم أو النوع
- عرض إحصائيات عن الصلاحيات

### 2. إضافة صلاحية جديدة
- اضغط "إضافة صلاحية"
- أدخل اسم الصلاحية
- حدد الأدوار المناسبة
- احفظ

### 3. تعديل صلاحية
- اضغط "تعديل" بجانب الصلاحية
- عدل الاسم والأدوار
- احفظ التغييرات

### 4. إعادة إنشاء الصلاحيات
- اضغط "إعادة إنشاء صلاحيات الأنظمة"
- سيتم حذف جميع الصلاحيات الحالية
- إعادة إنشائها من الكنترولرات
- **تحذير:** هذه العملية لا يمكن التراجع عنها

## 🎨 المميزات المرئية

### الألوان المستخدمة
- **أحمر** - الأدوار الأساسية (admin, super-admin)
- **أزرق** - أدوار المديرين
- **أزرق فاتح** - أدوار الموظفين
- **رمادي** - أدوار أخرى

### البدجات الصلاحيات
- **أزرق** - صلاحيات العرض (index, view)
- **أخضر** - صلاحيات الإضافة (store, create)
- **أصفر** - صلاحيات التعديل (update, edit)
- **أحمر** - صلاحيات الحذف (delete, destroy)
- **رمادي** - صلاحيات أخرى

## 🔧 الأوامر المفيدة

### مزامنة صلاحيات الأدمن
```bash
php artisan permissions:sync-admin
```

### مسح cache الصلاحيات
```bash
php artisan cache:forget spatie.permission.cache
php artisan cache:clear
```

### إعادة إنشاء الصلاحيات من الكنترولرات
```bash
php artisan permissions:sync-controllers
```

## 📝 نصائح وأفضل الممارسات

### 1. إدارة المستخدمين
- استخدم الأدوار بدلاً من الصلاحيات المباشرة
- راجع سجل التغييرات بانتظام
- تجنب منح صلاحيات واسعة للمستخدمين الجدد

### 2. إدارة الأدوار
- أنشئ أدوار محددة لكل قسم
- استخدم تسمية واضحة ومفهومة
- وثق الغرض من كل دور

### 3. إدارة الصلاحيات
- تتبع الصلاحيات المضافة/المحذوفة
- راجع الصلاحيات غير المستخدمة
- استخدم الوصفات المنطقية للأسماء

## 🆘 استكشاف الأخطاء

### صفحات فارغة بعد التغييرات
1. مسح cache الصلاحيات
2. تسجيل الخروج والدخول مجدداً
3. تحقق من تفعيل Gate::before

### خطأ 403 على صفحات الإدارة
1. تأكد من أن المستخدم لديه الدور المناسب
2. تحقق من صلاحيات الدور
3. راجع إعدادات AuthServiceProvider

### الصلاحيات لا تعمل
1. شغل مزامنة صلاحيات الأدمن
2. تحقق من middleware المسارات
3. راجع الـ cache
